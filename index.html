A save-state requires the emulator core to serialize CPU, memory, GPU and device state. This prototype can import, export and cloud-back-up save files; true instant-resume save states become available when the core is integrated.

Display & performance

Performance note: 3DS emulation is CPU- and GPU-intensive. The shell is lightweight, but actual Chromebook performance depends on the eventual WebAssembly core and graphics backend.

Core integration

No compatible browser 3DS core is installed in this prototype. The adapter hook expects a core that can load a cartridge, draw to the two canvases, accept button/touch input, and expose save-data serialization.

A Panda3DS browser port was demonstrated running games in Chrome with WebAssembly and WebGL2. Its developer currently lists the public player as offline and says the source will return with a later release. The main Panda3DS desktop repository is not a drop-in browser build. Orbit stays in safe shell mode until we have the released browser-core source and can build and test it. Browser-port status · Developer's technical notes · Panda3DS source
